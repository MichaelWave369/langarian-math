# Kimi v1 Harvest Branch

This folder preserves Kimi's `Langarian Math v1.0` material as an upstream experimental artifact.

## Status

**Experimental harvest only. Not trunk.**

The trunk remains **Langarian Math v0.2 FKC + v0.2.1 Epistemic Receipt Patch**. Concepts from this folder may graduate only after they are renamed, tested, and made compatible with the trunk claim boundary.

## Harvested safely into trunk

- Finite complex space helper: `src/langarian/spaces.py`
- Norm-preserving rotation demo: `src/langarian/dynamics.py`
- Nearest glyph scoring: `GlyphDictionary.nearest_with_score()`
- Additional tests for finite-space and dynamics behavior

## Downgraded / not promoted

- `bridge_naturality` claims are not accepted as category-theoretic naturality.
- RKHS/frame claims are not accepted from the stub dictionary.
- Symplectic/Hamiltonian theorem language is not accepted from the demo.
- Emotional examples remain interpretive/model demonstrations, never formal proof.
- `v1.0` naming is not accepted as trunk version.
